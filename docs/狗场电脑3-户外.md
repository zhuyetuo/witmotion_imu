# 佛山博朗旺 · 电脑3（户外活动区）· 操作备忘

3 路摄像头拍户外那块围起来的空地，机位号 cam7 / cam8 / cam9；**12 个项圈全写上，连得上哪个录哪个**。

**连项圈录（默认）只开 2 路摄像头（cam7 / cam8）+ 12 路蓝牙**；只录像（`VIDEO_ONLY=1`）才开全部 3 路。
哪两路由场地文件里的 `CAMERAS_IMU` 决定，想换就改那里。

为什么 12 个全写：每只狗两个项圈轮换，一个戴着（狗在户外）、一个在另一间屋子充电。充电那几个这台够不着、或者被电脑1/2 连着，就连不上——连不上的不出文件、不传，平台上不会多出空样本。

一个项圈同一时间只能被一台电脑连上：狗在户外时多半是这台先连上；狗回单间后这台连不上了，电脑1/2 会重新连回去。同一个项圈一天的数据会分在两台电脑上，平台按时间各成样本；切换那一会儿会丢一点数据。

场地配置：`sites/佛山博朗旺_狗场3.env`（别名 `bolangwang3`）。

## 装机

跟另外两台一样：仓库放 D:，离线安装包放 `.tools/`（见 `.tools/README.md`），然后

```bash
./setup_windows.sh
echo 佛山博朗旺_狗场3 > sites/.current      # 记住这台是哪个场地，之后可以不写 SITE=
cmd //c install_autostart.bat bolangwang3    # 开机自动录 + 每天自动传 NAS
```

## 第一次：核对摄像头索引（必须做）

配置里 cam7/8/9 对应的索引 0/1/2 是**占位**，没核对过。插好 3 路摄像头后：

```bash
SITE=佛山博朗旺_狗场3 ./record_multicam.sh --probe                 # 这台认到几路、索引是几
PREVIEW=1 DEBUG=1 SITE=佛山博朗旺_狗场3 ./record_multicam.sh       # 看画面，认哪路拍哪个角度
```

画面上标着 cam7 / cam8 / cam9，对不上就改 `sites/佛山博朗旺_狗场3.env` 里 `CAMERAS` 第二列的数字，
顺手在注释里写上每路拍的是哪个角度。换 USB 口索引就会变，换了要重新核对。

## 每天开录

```bash
SITE=佛山博朗旺_狗场3 ./record_multicam.sh
```

录出来 cam7 / cam8 每路一份 `…_cam7_raw.mp4`（不带 imu 号，拍全场），每个连上的项圈一份 `…_cam7_imuN_raw.csv`。
平台导入时，这一场每只狗的样本都挂这两路户外画面。

**第一次先测蓝牙**（12 个一起连，普通适配器一般稳稳 6~7 个）：

```bash
SITE=佛山博朗旺_狗场3 ./check_ble_capacity.sh --duration 600
```

看连上的那几个是不是都在 50Hz 左右；掉得厉害就再插一个 USB 蓝牙适配器。

**默认开监控墙**：3 路画面拼在一个窗口里，一眼看全场；点一格放大、再点还原。不影响录像（录下来的还是每路原尺寸）。
临时不要就 `WALL=0 SITE=佛山博朗旺_狗场3 ./record_multicam.sh`。

## 传 NAS

```bash
SITE=佛山博朗旺_狗场3 ./daily_archive.sh            # 处理昨天 + 补传之前失败的
DRY_RUN=1 SITE=佛山博朗旺_狗场3 ./daily_archive.sh  # 只打印要做什么
```

跟电脑1/2 写**同一个** NAS 日期目录（`2026_11_11_bolangwang` 这种），三台的机位号不重复，不会撞。

## 只录像、不连项圈

命令前面加 `VIDEO_ONLY=1`，不用改任何文件：

```bash
VIDEO_ONLY=1 SITE=佛山博朗旺_狗场3 ./record_multicam.sh
```

开头会打「只录像模式（VIDEO_ONLY=1）」，3 路摄像头全开。传 NAS 照常 `SITE=佛山博朗旺_狗场3 ./daily_archive.sh`，只传三路视频（没有项圈数据可传）。

想一直只录像（开机自动录也只录像）：把 `sites/佛山博朗旺_狗场3.env` 里的 `VIDEO_ONLY="0"` 改成 `"1"`。

## 别做的事

- **别跑 cleanup_gouchang.sh 清这台的目录** —— 它会把不带 imu 号的 `_cam7_raw.mp4` 当成多余的删掉，而这台传 NAS 靠的就是它。
- **别把机位号改成 1..6** —— 那是电脑1/2 的单间，传到 NAS 上会跟它们的文件撞。
